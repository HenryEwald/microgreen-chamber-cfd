# kOmegaSST flow animation — laminar-tuned clip (0.08 m/s)

This is the **like-for-like** version: the same 0 – 0.08 m/s colour clip as the laminar
`doc/animation_recirc/`, so the two can be played side by side against one scale.

**It saturates almost everywhere, and that is the point.** The kOmegaSST chamber moves ~1.8×
faster than the laminar one (+76 % on the tray mean, `validation/transient_matrix.md` §4e), so a
threshold chosen for the laminar recirculation sits below most of this field.

For a legible picture of this case's structure, use **`doc/animation_komega_retuned/`**
(0.14 m/s clip) — which also carries the full README, including the measurement showing this
arm has relaxed to a steady state and why the animation is nearly static.

39 frames, t = 48 → 57.5 s at 0.25 s, mid-width slice x = 60 mm.
